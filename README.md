# 🏠 Análise Exploratória de Dados: Imóveis à Venda em São Paulo

Este repositório apresenta uma análise descritiva e exploratória de dados sobre **apartamentos à venda na cidade de São Paulo**, como parte do meu **Mestrado em Ciência da Computação**. O objetivo é compreender como variáveis socioeconômicas e espaciais influenciam o **valor por metro quadrado** dos imóveis.

## 📅 Contexto
O dataset foi fornecido previamente pelo professor e contém dados coletados via web scraping, enriquecidos com:
- Distância ao metrô
- Expectativa de vida
- Renda per capita
- IDH do bairro
- Coordenadas geográficas (latitude e longitude)

---

## 🔧 Tecnologias Utilizadas
- Python 3.10+
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

---

## 🔍 Principais Análises Realizadas
- Estatísticas descritivas (média, mediana, desvio padrão)
- Histogramas para variáveis numéricas e categóricas
- Gráficos de dispersão entre `valor_m2` e:
  - Expectativa de vida
  - Renda per capita
  - Distância até o metrô
- Boxplots de `valor_m2` por faixa de IDH
- Ranking dos 10 bairros com maior e menor valor médio por m²
